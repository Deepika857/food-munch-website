# Food Munch – Responsive Food Website

## Overview
Food Munch is a responsive food and restaurant website designed to present food categories, highlight food service benefits, and provide delivery and payment information through a clean, user-friendly interface.

## Features
- Responsive navigation bar
- Hero banner with call-to-action buttons
- Why Choose Us section
- Food menu cards and categories
- Healthy food promotional section
- Delivery and payment information
- Gift voucher modal
- Social media section and footer

## Technologies Used
- HTML5
- CSS3
- Bootstrap

## Getting Started
1. Clone or download this repository.
2. Open the project folder.
3. Open `index.html` in a web browser.
4. Ensure you have an internet connection for the externally hosted images, fonts, and CDN resources.
